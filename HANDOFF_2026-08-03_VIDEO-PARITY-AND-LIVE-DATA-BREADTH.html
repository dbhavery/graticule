Correction to carry forward. I told Don that dual/quad pane was expensive because "N panes is N WebGL contexts". That reasoning was lazy. Browsers allow roughly 16 contexts, so four is fine, and better still, RadarScope's extra panes show raster products of the same view, which can be plain 2D canvases drawing the same tiles with no extra WebGL context at all. Build it the 2D way.

Traps this codebase has already sprung

Cesium

  • Render errors are invisible. Cesium catches exceptions during render(), shows its own panel and stops drawing. Nothing reaches window.onerror. Hook scene.renderError and assert on .cesium-widget-errorPanel.
  • minimumLevel without a rectangle detonates the tile graph. Adding a layer walks every loaded quadtree tile; a level-0 root at minimumLevel: 14 asks for 16384×8192 skeletons. Measured 37.4s of blocked main thread, then RangeError, then the renderer process dies. Always pass a bounding rectangle. Gating on camera altitude does not help — root tiles stay loaded at every zoom.
  • imageryLayers.add() returns undefined, unlike addImageryProvider. Assigning its result and then setting a property throws, and if that runs during init it silently aborts the rest of the bootstrap so no UI wiring happens.
  • Label atlas overflow. One texture atlas per LabelCollection, allocated eagerly and ignoring distanceDisplayCondition for allocation. Roughly 3,000 labels throw. The 5,732 cameras cap label visibility at 120km for this reason.
  • Non-finite positions corrupt the frustum. Roughly 900 of 2,181 ALERTCalifornia records ship [null, null]. They are dropped server-side; the verifier asserts zero reach the client.
  • requestRenderMode was never set despite ~20 requestRender() calls already in the code, so all of them were no-ops. Now on with maximumRenderTimeChange: 0.5. Anything that mutates the scene from a timer must call requestRender() or it will freeze.

JavaScript and CSS

  • Temporal dead zone. A const declared below const settings but read inside loadSettings() throws before let viewer is reached. Looks like "the app does not boot" with a clean node --check. Diagnose with typeof x throwing, which proves TDZ rather than undeclared.
  • let at top level of a classic script is script-scoped, not on window. Playwright probes must use bare identifiers with typeof x !== 'undefined'.
  • localStorage defeats new visual defaults. There is a renderEpoch integer; bump it and list the keys to drop.
  • The stylesheet is on a token scale now (7 font sizes, 2 radii, 3 tracking values). A raw px in font-size, border-radius or letter-spacing is a bug. grep proves there are none.
  • Static is mounted at /static, not the document root. A bare fetch('data/x.json') 404s, and a 404 does not fire requestfailed, so it looks like silence.

Upstream data

  • World Bank region strings carry a trailing space. "Sub-Saharan Africa ". This silently unmapped most countries and produced a zero for Latin America. The build script's --verify caught it.
  • Open-Meteo defaults to metric. Without unit parameters the legend printed 35.6°F for a 96°F afternoon.
  • Open-Meteo back-fills the tail of older runs with the latest run's values, so a "last value" legend prints identical numbers across four runs that genuinely differ by up to 10°F earlier in the window.
  • NWS sends maxHailSize, not hailSize. The old code read the wrong key, so hail size had never once rendered.
  • The source population board contradicts itself. Its TODAY panel implies ~217k births/day while its own THIS YEAR panel implies ~362k. The second is right. Reproduce the layout, not the arithmetic.

Verification standard Don expects

  • Look at the pixels. "Verified" means the screenshot was opened and read, not that the code seemed right. Every UI change in this session was screenshotted and inspected, and that is how four detail-panel defects and the toolbar collision were found.
  • A check that cannot fail proves nothing. The spotter feed returned zero features on a quiet night; the parser was therefore run against a captured placefile that did carry a report, plus a garbage-input negative control.
  • Test each arm separately. Three camera networks were each opened and decoded, because one working would have hidden two broken ones.
  • Assert the negative. The tool strip test asserts that entering draw mode does not mark the basemap bar — the assertion that fails on the old markup.
  • Do not claim numbers this machine cannot measure. See the SwiftShader note at the top.
  • Open every visual change in Don's browser automatically: powershell -NoProfile -Command "Start-Process 'http://127.0.0.1:8731/'". cmd //c start fails silently on special characters.
